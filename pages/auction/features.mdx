# Особенности аукциона

1. **Аукцион на всех серверах**:
Вещи, выставленные на аукционе, могут купить игроки с любого сервера анархии.

<a href="funtime.su/"><img src="https://i.ibb.co.com/vvzwLP8y/image.png" alt="Товар выставлен на 11 анархии"></a>

<a href="funtime.su/"><img src="https://i.ibb.co.com/d4PWGVDm/image.png" alt="Товар доступен к покупке на 51 анархии"></a>

2. **Категории**: В основном меню вы можете смотреть все вещи по категориям. Например, инструменты, блоки, предметы для грифа и т.д.

<a href="funtime.su/"><img src="https://i.ibb.co.com/6JFFrc91/image.png" alt="Категории в основном меню"></a>

<a href="funtime.su/"><img src="https://i.ibb.co.com/mC2GQcd3/image.png" alt="Список всех категории"></a>

3. **Посмотреть товары игрока**: Вы можете увидеть все вещи, которые продаёт один игрок. Для этого напишите команду или нажмите правой кнопкой мыши на товар.

<a href="funtime.su/"><img src="https://i.ibb.co.com/zhFyGkDL/image.png" alt="Товары игрока varcock"></a>

4. **Хранилище**: Здесь хранятся ваши товары, которые вы продаёте, и вещи, которые вы купили, но не поместились в инвентарь.

<a href="funtime.su/"><img src="https://i.ibb.co.com/pvtVJDHs/image.png" alt="Хранилище Аукциона"></a>

5. **Перевыставить товары**: Вы можете обновить свои товары, чтобы они появились выше в списке и были дольше на продаже. Для этого нажмите на часы в хранилище или используйте команду (нужна привилегия Князь или выше).

<a href="funtime.su/"><img src="https://i.ibb.co.com/G4DymRfH/image.png" alt="Перевыставление товаров"></a>

6. **Поиск предметов**: Вы можете искать вещи по названию, написав команду с названием, и увидеть список подходящих товаров.

<a href="funtime.su/"><img src="https://i.ibb.co.com/Xrw87yjD/image.png" alt="Ввод команды для поиска"></a>

<a href="funtime.su/"><img src="https://i.ibb.co.com/Y7xMGZc7/image.png" alt="Все предметы удовлетворяющие поисковому запросу"></a>

7. **Продажа в оффлайн**: Вы можете выставить вещи на продажу и выйти из игры. Когда вы вернётесь на сервер, вам зачислят монеты за продажу.

<a href="funtime.su/"><img src="https://i.ibb.co.com/gbbLt3Rn/image.png" alt="Выданные монеты за продажу товара, хотя я был не в сети"></a>

8. **Посмотреть содержимое**: Вы можете посмотреть, что внутри шалкеров и мешков, перед покупкой.

<a href="funtime.su/"><img src="https://i.ibb.co.com/Y721g5ZY/image.png" alt="Мешок с каким-то содержимым"></a>
<a href="funtime.su/"><img src="https://i.ibb.co.com/HT0DMWK9/image.png" alt="Содержимое мешка"></a>
<a href="funtime.su/"><img src="https://i.ibb.co.com/RkvZLfYy/image.png" alt="Шалкер с каким-то содержимым"></a>
<a href="funtime.su/"><img src="https://i.ibb.co.com/DfZLJJ8y/image.png" alt="Содержимое шалкера"></a>

9. **Простое указание цен**: Когда вы выставляете вещь на продажу, то, например, вы можете написать цену просто 2kk вместо 2000000. Плагин сам покажет точное число с запятыми.

<a href="funtime.su/"><img src="https://i.ibb.co.com/xbYwbWW/image.png" alt="Удобное отображение цен"></a>
